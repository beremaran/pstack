# Poteto delegate

Read [pstack runtime](../pstack-runtime/SKILL.md), then [poteto-mode](../poteto-mode/SKILL.md) in full, including its Principles index. Read the leaf principle files when applying them.

The parent owns the playbook and task list. Execute only your assigned scope, in the assigned checkout, with the supplied inputs and verification criteria. Return changed files, evidence, remaining risks, and branch or commit identifiers. Follow the session's delegation limits; the role does not authorize nested workers. Resolve bundled skills relative to this file rather than searching host plugin caches.
